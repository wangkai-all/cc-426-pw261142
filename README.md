# 跨来源事件去重与指标分析系统

同一事件在不同来源（911 报警、传感器、社交媒体）各自编号、没有统一 ID。
本系统从零生成此类虚构数据，实际完成 **接收 → 匹配 → 指标 → 人工裁决** 全流程，
所有匹配依据均为**可解释证据条目**（电话一致、门牌街道一致、时间差、距离、
文本词集重合度），不用任何不可解释的模型分数代替依据。

## 运行

```bash
python3 -m event_dedup.simulate     # 端到端模拟（推荐入口，含全部断言验证）
python3 -m event_dedup.web          # 审阅网页 http://127.0.0.1:8077
```

四个服务分别运行，通过 `data/` 下的只追加日志文件协作：

| 服务 | 命令 | 输入 → 输出 |
|---|---|---|
| 接收日志 | `python3 -m event_dedup.ingest` | `data/raw/*.jsonl` → `records.jsonl` |
| 候选匹配 | `python3 -m event_dedup.matcher` | `records.jsonl` → `candidates.jsonl` |
| 指标计算 | `python3 -m event_dedup.metrics` | 三份日志快照 → `metrics_runs.jsonl` |
| 审阅网页 | `python3 -m event_dedup.web` | 读取全部日志 → 写 `decisions.jsonl` |

## 关键设计决策

**1. 保存候选图，而非按块重建。**
候选边（含全部证据）持久化在 `candidates.jsonl`，边 ID 稳定（`r0007-r0008`）。
人工裁决锚定在边 ID 上；重跑 matcher 只会发现新边、永不删旧边。
分块索引（同类别 + 15 分钟窗 + 400 米网格）每次临时重建，仅用于发现候选对。
若只存分块，重算参数一变，已有裁决就会失去锚点。

**2. 保守 vs 宽松 vs 裁决，三视图对比指标。**
- 保守：仅自动接受强证据边（权重合计 ≥ 3.0 或强规则），**团约束**聚类；
- 宽松：≥ 1.6 即接受，**连通分量**聚类，直径 > 1 的簇标记为链式风险；
- 裁决：保守基线 + 人工确认 − 人工驳回，团约束聚类，系统实际使用的视图。

仪表盘并排展示三视图指标（事件数、折叠重复、跨来源事件、分来源贡献），
可直观比较两种去重口径对指标的影响；人工裁决在两个界之间移动。

**3. 防链式相似误合并：团约束。**
保守/裁决视图中，一个记录要并入簇，必须与簇内**所有**成员都有已接受边。
因此 A~B、B~C 但 A!≁C 时，C 永远无法借 B 链入——即使是人工确认也会被
阻止并列入"未解决"（模拟第 8 步演示：T3 借 T2 链入 T1 被阻止）。
宽松视图故意不加此约束，用于展示链式误合并的风险及其桥接边。

**4. 人工裁决反向改变去重关系与贡献。**
裁决是只追加日志（`decisions.jsonl`）：确认/驳回覆盖自动策略，
撤销 = 追加 revert 补偿条目，历史永不改写。每次裁决后重放日志即得新簇，
分来源贡献、跨来源事件数随之变化（模拟第 11 步打印前后对比）。

**5. 两次裁决交错。**
每条裁决记录提交人所见的日志位置 `base_dseq`。若针对同一条边，
在他人的视图快照之后已有改动，重放时标记 `stale_based` 冲突；
同一边多条生效裁决按后写覆盖并显式列出（模拟第 5 步：乙基于旧视图
驳回甲已确认的边 → 冲突被标记 → 乙撤销自己的驳回）。

**6. 旧计算晚到。**
指标运行启动时记录基准版本（三类日志行数），写回前重新读取版本，
不一致则标记 `stale`——结果保留在历史中可查，但不成为"当前指标"
（模拟第 4、10 步：4 秒慢速计算写回时已被 7 条裁决超越）。

**7. 拆回后可还原原始记录。**
`records.jsonl` 自 ingest 写入后不可变；簇完全由日志重放派生。
撤销任何裁决，记录即还原为原始单例（模拟第 12 步验证 records.jsonl
与 ingest 刚完成时逐字节一致）。

## 虚构数据中的测试情形（`gen_data.py`）

- 普通多来源事件：证据充分，保守策略自动合并；
- 同一报警人重复来电：电话强证据；
- 证据不足的跨来源对：落入待人工裁决区间（1.6 ≤ score < 3.0）；
- **链式陷阱** T1/T2/T3：三起独立追尾，两两相近但首尾不相干——
  宽松视图链式误合并（直径 2 被标记），团约束视图保持独立；
- **难分负样本** E13/E14：两起独立火灾相距 150 米、4 分钟——
  宽松误合并，保守正确分离。

模拟末尾用真值（仅评估用，系统不读取）打印三视图的成对精确率/召回率：
保守 1.00/0.29，宽松 0.54/1.00，裁决 1.00/0.43 ——
人工裁决在不牺牲精确率的前提下把召回从 0.29 提到 0.43。

## 目录

```
event_dedup/
  common.py     路径、JSONL、状态版本
  gen_data.py   虚构数据生成
  ingest.py     接收日志服务（规范化，幂等）
  matcher.py    候选匹配服务（分块 + 可解释证据）
  decisions.py  裁决日志（撤销、交错检测）
  policy.py     三视图与聚类（团约束 / 连通分量 + 链式风险）
  metrics.py    指标计算器（快照、stale 检测）
  state.py      状态装配（重放全部日志）
  web.py        审阅网页（证据、撤销、指标变化、未解决）
  simulate.py   端到端模拟与断言
data/           运行产物（git 忽略）
```
